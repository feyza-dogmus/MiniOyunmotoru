# Mini Oyun Motoru

## Konu Seçimi: C — Mini Oyun Motoru

Bu projeyi seçmemin nedeni, oyun motorlarının nesne yönetimi, davranış farklılıkları ve genişletilebilirlik gibi tasarım sorunlarını en somut biçimde ortaya koymasıdır. Oyun nesneleri (oyuncu, düşman, toplanabilir nesne) arasındaki davranış farklarının if-else zincirleriyle yönetilmesi, tasarım örüntülerinin neden gerekli olduğunu doğrudan hissettiren bir senaryodur. Ayrıca oyun geliştirme alanına olan ilgim bu konuyu daha motive edici kılmaktadır.

## Proje Açıklaması

Basit bir 2D konsol tabanlı mini oyun motoru. Oyuncu, düşman ve toplanabilir nesneleri yönetir. Proje, yazılım tasarım örüntülerini aşamalı olarak uygulayarak evrimleşecektir.

## Nasıl Çalıştırılır

```bash
cd src
javac Main.java GameObject.java GameManager.java Renderer.java
java Main
```
